# سطحة الرياض - أسرع خدمة نقل سيارات 24 ساعة

هذا المشروع هو تطبيق ويب متطور لخدمات "سطحة الرياض"، مبني باستخدام تقنيات Next.js 15 و React و Tailwind CSS، ومحسن بالكامل لمحركات البحث (SEO) وجاهز لحملات إعلانات جوجل (Google Ads).

## المميزات الرئيسية

- **واجهة مستخدم عصرية باللغة العربية:** متوافقة تماماً مع القراءة من اليمين إلى اليسار (RTL).
- **تحسين محركات البحث (SEO):** استهداف دقيق لجميع أحياء الرياض (شمال، شرق، غرب، جنوب) لضمان أفضل ظهور محلي.
- **جاهزية إعلانات جوجل:** صفحة هبوط محسنة لزيادة معدل التحويل (Conversion Rate).
- **اتصال فوري:** أزرار اتصال مباشر ومراسلة واتساب عائمة لسهولة الوصول في حالات الطوارئ.
- **عرض الأسطول:** قسم مخصص لعرض أنواع السطحات المتاحة (هيدروليك، عادية، فل داون).
- **خدمة تقدير الحوادث:** قسم مخصص لنقل سيارات الحوادث إلى مراكز التقدير المعتمدة.

## التقنيات المستخدمة

- **Next.js 15 (App Router)**
- **Tailwind CSS**
- **Shadcn UI**
- **Lucide Icons**
- **TypeScript**

## البدء في العمل

أولاً، قم بتثبيت التبعات:

```bash
npm install
```

ثم، ابدأ خادم التطوير:

```bash
npm run dev
```

افتح [http://localhost:9002](http://localhost:9002) لمشاهدة الموقع.
